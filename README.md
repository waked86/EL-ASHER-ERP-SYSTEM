# نظام مصنع العاشر ERP

نظام إدارة مصنع عربي متعدد المستخدمين، محافظ على لوحة التحكم الأصلية واتجاه RTL والتقارير والتصدير.

## الحالة

- الواجهة الأصلية محفوظة في `index.html`.
- خادم Express داخل `server.js`.
- PostgreSQL لحفظ الحالة المركزية بين الأجهزة.
- تسجيل دخول بكلمة مرور مشفّرة وCookie جلسة.
- إنشاء حساب المدير عند التشغيل الأول.
- مزامنة بيانات الحركات والحسابات والمصروفات بين المستخدمين والأجهزة.
- المستودع يجب أن يظل Private لأن البيانات التشغيلية تتضمن بيانات عملاء.

## متغيرات Railway المطلوبة

- `DATABASE_URL`: يتم ربطه تلقائيًا بمتغير PostgreSQL من خدمة قاعدة البيانات.
- `JWT_SECRET`: قيمة عشوائية طويلة لحماية جلسات الدخول.
- `NODE_ENV=production`

## أول تشغيل

افتح رابط Railway، ثم أنشئ حساب المدير الأول. بعد ذلك تظهر البيانات من قاعدة PostgreSQL للمستخدمين المسجلين.

> النسخة الحالية تحفظ بيانات لوحة التحكم في سجل JSON مركزي متوافق مع النموذج الأصلي، ويمكن لاحقًا تقسيم الجداول إلى كيانات منفصلة دون تغيير تجربة المستخدم.
