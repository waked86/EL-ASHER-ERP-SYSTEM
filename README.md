# نظام مصنع العاشر ERP

نسخة الأساس الأصلية من لوحة التحكم العربية قبل تحويل التخزين المحلي إلى نظام متعدد المستخدمين.

## الحالة

- الواجهة الأصلية محفوظة في `index.html`.
- الخطوة التالية: إضافة Backend وPostgreSQL وتسجيل الدخول والصلاحيات والمزامنة بين الأجهزة.
- المستودع يجب أن يظل Private لأنه يحتوي على بيانات تشغيلية وبيانات عملاء.
